Help Center

Frequently Asked Questions

Find fast answers regarding system integrations, ANPR hardware requirements, portal management, and billing loops.

How accurate is the ANPR camera system in low-light conditions?

Our Neural Network ANPR system delivers over 99.4% reading accuracy. It uses specialized infrared shutter controls to identify license plates instantly under heavy rain, dense fog, or complete night darkness.

Can the client portal integrate with existing corporate ERP systems?

Yes. Smart Parking includes comprehensive REST API webhooks. You can easily synchronize active employee directories, export weekly accounting logs (CSV), and import invoicing data automatically into platforms like SAP or Microsoft Dynamics.

What happens if the local facility internet connection goes offline?

Every gate controller lane operates on decentralized databases. They can validate VIP registrations, log session details, and trigger barriers offline. Once internet connectivity is restored, the logs sync back up with the cloud database automatically.
